# 새 법안 추가하기 (처음부터 끝까지)

지금까지 4개 법안(건보 특사경법, 고령자돌봄주택법, PM법, 편의점 상비약법)을 만든 순서를 그대로 정리한 것입니다.
명령은 모두 저장소 맨 위 폴더에서 실행합니다.

## 0. 폴더 만들기

```bash
python3 scripts/new_bill.py rent-law --bill-no 2223353
```

- `data/bills/rent-law/`에 `bill.json`, `shorts.json`, `sources.md` 빈 양식이 생깁니다.
- `--bill-no`를 주면 국회 자동 추적 목록(`data/assembly/tracked.json`)에도 들어가서, 2시간마다 진행 상황이 갱신됩니다.
- `data/app/settings.json`의 `bill_order` 맨 뒤에 id가 붙습니다. 앞에 보이게 하려면 순서를 옮기세요.
- `bill.json`은 `"draft": true`로 시작해서, 다 채울 때까지 앱에 나오지 않습니다.

## 1. 자료 모으기 → `sources.md`

- 기사, 국회 의안정보시스템(의안번호로 검색), 검토보고서를 모읍니다.
- 자료마다 매체, 제목, 날짜, URL, 그리고 핵심 사실만. 숫자와 주장에는 누가 말했는지 붙입니다.
- 찬성 쪽과 반대 쪽 자료를 둘 다 찾습니다. 한쪽만 있으면 쇼츠에서 찬반 장면을 뺍니다.
- 확인하지 못한 것은 `## 메모`에 적습니다. 예: `data/bills/pm-law/sources.md`

## 2. 쇼츠 문구 → `shorts.json`

1. `shorts/prompt.md`의 [시스템 프롬프트]와 [사용자 프롬프트]에 `sources.md`를 넣어 LLM에 보냅니다.
2. 받은 JSON을 `shorts.json`에 붙여 넣고, `sources.md`와 하나씩 대조해 검수합니다.
   - 자료에 없는 사실, 주체 없는 숫자, 찬반 분량 차이, 단계(stage) 확인
   - **화면 문구에 중간점(·) 금지.** 쉼표, "와/과", 띄어쓰기로 씁니다.

## 3. 쇼츠 만들기 → `shorts.mp4`, `poster.jpg`

```bash
python3 shorts/render.py data/bills/rent-law/shorts.json --preview   # 장면별 그림 확인 (shorts/build/rent-law/preview/)
python3 shorts/render.py data/bills/rent-law/shorts.json             # 영상과 썸네일 (약 15초)
```

글자가 넘치면 렌더하지 않고 어떤 칸이 긴지 알려 줍니다. 그 칸을 줄이고 다시 실행합니다.

## 4. 앱 카드 → `bill.json`

1. `templates/prompt_bill_card.md`의 프롬프트에 같은 `sources.md`를 넣어 LLM에 보냅니다.
2. 받은 JSON을 `bill.json`에 붙여 넣고 검수합니다. `shorts.json`과 사실(날짜, 단계, 숫자)이 같아야 합니다.
3. 다 됐으면 `"draft": false`로 바꿉니다.

## 5. 확인하고 올리기

```bash
python3 scripts/build_site.py --serve     # 검사 후 http://localhost:8000 에서 확인
```

- 홈, 법안 상세, 쇼츠 탭, 알림 탭에서 새 법안이 제대로 보이는지 봅니다.
- 커밋해서 `main`에 올리면 GitHub Pages에 자동으로 배포됩니다. 검사에 실패하면 Actions 탭에 이유가 나옵니다.

## 법안 상태가 바뀌었을 때

- 국회 데이터(`data/assembly/`)는 자동으로 바뀝니다. `changes.json` 맨 위에 무엇이 바뀌었는지 남습니다.
- 쇼츠 법안의 카드와 영상은 사람이 고칩니다: `sources.md`에 새 자료 추가 → `bill.json`의 `cur`, `status`, `when`, `date`, `subs`, `notices` 수정 → 필요하면 `shorts.json`의 `status`와 `as_of`를 고치고 다시 렌더.

## 법안 빼기

`data/bills/<id>/` 폴더를 지우고 `data/app/settings.json`에서 id를 지웁니다(검사가 알려 줍니다). 잠깐 숨기기만 하려면 `"draft": true`.
