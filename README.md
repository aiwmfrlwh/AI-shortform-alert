# 법안톡: 국회 법안을 알림과 짧은 영상으로

바른정책아카데미 AI 팀 프로젝트입니다.

## 어떤 서비스인가요?

국회에는 매일 새 법안이 올라오지만, 내 생활과 관련된 법이 지금 어디까지 왔는지 알기는 어렵습니다.
**법안톡**은 이 문제를 두 가지 방법으로 풉니다.

1. **알림**: 관심 있는 법안이 다음 단계로 넘어가면 알려 줍니다.
   법안은 보통 이 순서로 진행됩니다.
   `발의(처음 제출)` > `소관 상임위원회 심사` > `법제사법위원회 심사` > `본회의 표결` > `공포(법으로 확정)`
2. **쇼츠 영상**: 법안 내용, 찬성과 반대 의견, 현재 단계를 1분이 안 되는 세로 영상으로 보여 줍니다.

**지금 바로 써 보기**: https://aiwmfrlwh.github.io/AI-shortform-alert/
휴대폰 브라우저로 열면 앱처럼 쓸 수 있습니다. 따로 설치할 필요는 없습니다.

## 어떻게 돌아가나요?

사람이 손대지 않아도 아래 과정이 저절로 반복됩니다.

1. **2시간마다** 컴퓨터가 국회 공식 자료(국회 Open API)를 확인합니다.
2. 새 법안이 올라왔거나 지켜보던 법안의 단계가 바뀌었으면 그 내용을 저장합니다.
3. 저장된 최신 자료가 웹사이트에 자동으로 반영됩니다.

이 일은 GitHub(코드를 저장하고 함께 작업하는 사이트)의 자동 실행 기능이 맡고 있습니다.

쇼츠 영상은 사람과 AI가 함께 만듭니다.

1. 팀원이 법안 정보와 관련 기사를 모아 문서 하나로 정리합니다.
2. AI가 그 자료를 읽고 영상에 들어갈 문구를 씁니다.
3. 팀원이 원래 자료와 비교해 틀린 내용이 없는지 확인합니다.
4. 프로그램이 문구를 정해진 디자인에 넣어 영상을 만듭니다.

| 폴더 | 들어 있는 것 | 이런 분이 보면 됩니다 |
| --- | --- | --- |
| `bill-alert-app/` | 실제 앱 화면, 앱 디자인, 완성된 쇼츠 영상, 쇼츠 만드는 틀 | 앱과 영상을 보고 싶은 분 |

## 새 법안 쇼츠를 만들고 싶다면

코딩은 필요 없습니다. 자료만 모아 주시면 됩니다.

1. [법안 쇼츠 데이터 규격](workspace/법안_쇼츠_데이터_규격.md) 문서를 엽니다.
2. 문서에 나온 네 가지를 모읍니다: 법안 기본정보, 관련 기사 2~6건, 찬성과 반대 주장, 현재 진행 단계.
3. 모르는 항목은 짐작해서 채우지 말고 비워 둡니다.
4. 정리한 파일을 팀에 넘기면 영상 제작은 이어서 진행합니다.

## 쇼츠를 만들 때 지키는 원칙

- **자료에 있는 사실만** 씁니다. 모르는 것은 쓰지 않습니다.
- **찬성과 반대를 같은 분량**으로 다룹니다. 한쪽 편을 들지 않습니다.
- 숫자를 쓸 때는 **누가 한 말인지** 함께 적습니다. (예: "OO협회는 이용자가 30% 늘었다고 밝혔다")
- "좋은 법", "나쁜 법" 같은 평가하는 말은 쓰지 않습니다.
- 화면 문구에는 가운뎃점을 쓰지 않습니다. 나열할 때는 쉼표나 "와/과"를 씁니다.

## 자주 쓰는 말 풀이

| 말 | 뜻 |
| --- | --- |
| 의안번호 | 법안마다 붙는 고유 번호 (예: 2218220) |
| 발의 | 국회의원이나 정부가 법안을 처음 국회에 내는 것 |
| 소관위 | 그 법안 분야를 맡은 국회 상임위원회 (예: 보건복지위원회) |
| 법사위 | 법제사법위원회. 법안 문구와 다른 법과의 충돌을 마지막으로 살핌 |
| 공포 | 통과된 법을 정부가 알리고 효력이 생기는 것 |
| API | 국회 같은 기관이 자료를 프로그램으로 가져갈 수 있게 열어 둔 창구 |
| GitHub | 이 프로젝트 파일이 저장된 곳. 누가 언제 무엇을 바꿨는지 기록이 남음 |

## 개발자용 안내

직접 프로그램을 실행해 보고 싶은 분을 위한 내용입니다. 위의 내용만으로도 프로젝트를 이해하는 데는 충분합니다.

**국회 자료 받기**
```powershell
cd api-server
copy .env.example .env
pip install openpyxl
python fetch_bill.py 2218220
```
`.env` 파일의 `=` 뒤에 국회 Open API 인증키를 넣습니다. 이 파일은 비밀번호와 같으니 카톡, GitHub, 채팅에 올리지 마세요. 자세한 방법은 [API 사용 가이드](api-server/API_사용_가이드.md)에 있습니다.

**앱을 내 컴퓨터에서 열기**
```powershell
cd bill-alert-app/web; python -m http.server 8000
```
그다음 브라우저에서 http://localhost:8000 을 엽니다.

**쇼츠 영상 만들기**
```powershell
pip install pillow
cd bill-alert-app/shorts-template; python render.py data/pm-law.json
```
Noto Sans CJK 글꼴과 ffmpeg가 필요합니다. 자세한 내용은 [쇼츠 템플릿 안내](bill-alert-app/shorts-template/README.md)를 보세요.

**자동 실행 설정** (`.github/workflows/`)
- `update-bills.yml`: 2시간마다 국회 자료를 확인하고, 바뀐 것이 있을 때만 저장합니다. 저장소 Secrets의 `ASSEMBLY_API_KEY`를 씁니다.
- `pages.yml`: 앱이나 자료가 바뀌면 웹사이트에 다시 올립니다.
